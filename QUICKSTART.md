# Quick Start

```sh
git clone https://github.com/haoyangzhang99/CodingAgentStatusBar.git
cd CodingAgentStatusBar
./install.sh
```

This is for OpenCode 2. For OpenCode 1, clone with `git clone -b opencode-v1 ...` instead; see
[Which Version to Install](README.md#which-version-to-install).

Then fully quit OpenCode (Cmd+Q) and reopen it. See [README.md](README.md) for what the
menu bar shows, updating, and uninstalling.
